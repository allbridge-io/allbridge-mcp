# Claude Code Example

Published package:

```bash
claude mcp add allbridge --env ALLBRIDGE_ETH_RPC_URL=https://your-eth-rpc.example.com -- npx -y @allbridge/allbridge-mcp@1.1.0
```

Local checkout (after `pnpm build`):

```bash
claude mcp add allbridge --env ALLBRIDGE_ETH_RPC_URL=https://your-eth-rpc.example.com -- node /absolute/path/to/allbridge-mcp/dist/index.js
```
